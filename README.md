# Hospital Buddy website
This is a polished front-end starter with Buddy profiles and a booking flow.

IMPORTANT: The Buddy phone numbers are placeholders. For a real service, use a backend/database so availability is checked and the assigned Buddy's real contact number is disclosed only after confirmation. Do not publish staff numbers in public JavaScript.

A free production architecture can be:
- GitHub Pages for the website
- Firebase free tier for bookings/database
- Admin login for assignment/confirmation
- WhatsApp/email notification after confirmation

Before launch, complete business/local compliance and obtain the required permission/clarification for any activity on hospital premises. Keep the independent-service disclaimer visible.
